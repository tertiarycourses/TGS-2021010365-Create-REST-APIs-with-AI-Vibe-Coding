# Lab 05 working copy

Use this self-contained FastAPI/SQLite/HTML-CSS-JavaScript project while completing **Validate Product and Customer Data**.

Focus: Define typed product and customer schemas with field-level and cross-field constraints.

Acceptance criterion: Invalid SKU, price, stock, email and status values are rejected before repository code; valid JSON becomes a typed model.

The database is created locally when the service starts. Do not submit `northstar.db`, `.env`, virtual environments, caches, or live credentials.
