# Lab 03 working copy

Use this self-contained FastAPI/SQLite/HTML-CSS-JavaScript project while completing **Split Routes and Reuse a Service Function**.

Focus: Refactor a monolithic FastAPI file into router and service modules without changing the contract.

Acceptance criterion: All baseline tests still pass and OpenAPI exposes each route exactly once.

The database is created locally when the service starts. Do not submit `northstar.db`, `.env`, virtual environments, caches, or live credentials.
