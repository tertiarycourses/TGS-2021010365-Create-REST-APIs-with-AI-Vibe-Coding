# Lab 11 working copy

Use this self-contained FastAPI/SQLite/HTML-CSS-JavaScript project while completing **Connect the Commerce Web App**.

Focus: Use fetch to power a responsive dashboard for products, customers and orders through FastAPI.

Acceptance criterion: The browser reads/writes only through FastAPI, SQLite state changes correctly and the UI remains usable at 375px and desktop widths.

The database is created locally when the service starts. Do not submit `northstar.db`, `.env`, virtual environments, caches, or live credentials.
