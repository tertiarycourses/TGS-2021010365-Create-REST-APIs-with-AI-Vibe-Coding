# Lab 02 working copy

Use this self-contained FastAPI/SQLite/HTML-CSS-JavaScript project while completing **Run the First FastAPI Service**.

Focus: Create and verify a typed product endpoint and its generated OpenAPI documentation.

Acceptance criterion: GET /health/live returns 200; /docs lists the product route; invalid path input returns structured 422 JSON.

The database is created locally when the service starts. Do not submit `northstar.db`, `.env`, virtual environments, caches, or live credentials.
