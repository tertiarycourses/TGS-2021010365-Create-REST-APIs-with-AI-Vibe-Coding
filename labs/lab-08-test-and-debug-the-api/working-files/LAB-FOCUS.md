# Lab 08 working copy

Use this self-contained FastAPI/SQLite/HTML-CSS-JavaScript project while completing **Test and Debug the API**.

Focus: Build a pytest regression suite, reproduce a seeded defect and verify the fix.

Acceptance criterion: The seeded test fails before the fix; the full suite passes after it; the regression assertion remains.

The database is created locally when the service starts. Do not submit `northstar.db`, `.env`, virtual environments, caches, or live credentials.
