# Lab 10 working copy

Use this self-contained FastAPI/SQLite/HTML-CSS-JavaScript project while completing **Implement SQLite CRUD and Orders Safely**.

Focus: Connect product, customer and order operations to parameterized SQL and atomic transactions.

Acceptance criterion: Catalog/CRM CRUD and order tests pass, insufficient stock rolls back fully, missing IDs map to 404 and SQL values are parameter-bound.

The database is created locally when the service starts. Do not submit `northstar.db`, `.env`, virtual environments, caches, or live credentials.
