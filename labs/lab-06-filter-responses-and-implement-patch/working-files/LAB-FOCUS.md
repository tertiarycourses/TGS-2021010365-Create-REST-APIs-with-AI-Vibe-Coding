# Lab 06 working copy

Use this self-contained FastAPI/SQLite/HTML-CSS-JavaScript project while completing **Filter Responses and Implement PATCH**.

Focus: Use response models and exclude_unset semantics for safe partial updates.

Acceptance criterion: PATCH changes only supplied fields and no internal database field appears in the JSON response.

The database is created locally when the service starts. Do not submit `northstar.db`, `.env`, virtual environments, caches, or live credentials.
