# Lab 07 working copy

Use this self-contained FastAPI/SQLite/HTML-CSS-JavaScript project while completing **Standardise Errors and Request Logs**.

Focus: Create predictable error responses and trace a request from status to log event.

Acceptance criterion: 404 and 409 use the same envelope; each response request ID locates one log trace; secrets are absent.

The database is created locally when the service starts. Do not submit `northstar.db`, `.env`, virtual environments, caches, or live credentials.
