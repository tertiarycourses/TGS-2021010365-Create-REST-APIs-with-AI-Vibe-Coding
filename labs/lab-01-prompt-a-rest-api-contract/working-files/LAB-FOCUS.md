# Lab 01 working copy

Use this self-contained FastAPI/SQLite/HTML-CSS-JavaScript project while completing **Prompt a REST API Contract**.

Focus: Convert Northstar Commerce requirements into a versioned OpenAPI-first route and data contract.

Acceptance criterion: The contract covers products, customers and orders, names 200/201/204/401/404/409/422 outcomes and validates as OpenAPI 3.1.

The database is created locally when the service starts. Do not submit `northstar.db`, `.env`, virtual environments, caches, or live credentials.
