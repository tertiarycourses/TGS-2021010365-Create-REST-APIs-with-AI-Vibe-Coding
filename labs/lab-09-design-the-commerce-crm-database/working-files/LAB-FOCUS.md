# Lab 09 working copy

Use this self-contained FastAPI/SQLite/HTML-CSS-JavaScript project while completing **Design the Commerce CRM Database**.

Focus: Create constrained products, customers, orders and order_items tables with relational integrity.

Acceptance criterion: Initialisation is idempotent and SQLite enforces unique SKU/email, valid money/stock, order status and foreign keys.

The database is created locally when the service starts. Do not submit `northstar.db`, `.env`, virtual environments, caches, or live credentials.
