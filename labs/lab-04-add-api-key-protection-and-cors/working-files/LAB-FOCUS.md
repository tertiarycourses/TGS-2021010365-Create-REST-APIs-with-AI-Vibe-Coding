# Lab 04 working copy

Use this self-contained FastAPI/SQLite/HTML-CSS-JavaScript project while completing **Add API-Key Protection and CORS**.

Focus: Implement a reusable API-key dependency and an explicit browser-origin allow list.

Acceptance criterion: Unauthorized writes return 401; a valid key succeeds; only the configured origin receives CORS permission.

The database is created locally when the service starts. Do not submit `northstar.db`, `.env`, virtual environments, caches, or live credentials.
