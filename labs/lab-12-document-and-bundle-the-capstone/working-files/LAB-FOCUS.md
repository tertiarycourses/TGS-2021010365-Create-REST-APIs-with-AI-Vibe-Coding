# Lab 12 working copy

Use this self-contained FastAPI/SQLite/HTML-CSS-JavaScript project while completing **Document and Bundle the Capstone**.

Focus: Produce a clean, testable release bundle with API docs, frontend assets and operational instructions.

Acceptance criterion: A clean copy installs, tests, starts, serves the storefront/CRM dashboard, completes catalog/customer/order flows and contains no secret or database file.

The database is created locally when the service starts. Do not submit `northstar.db`, `.env`, virtual environments, caches, or live credentials.
