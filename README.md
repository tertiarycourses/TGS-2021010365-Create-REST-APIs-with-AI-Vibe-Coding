## About the course

The official course retains its registered title and Applications Integration outcomes. Version 11.0 modernises the implementation around FastAPI, Pydantic, OpenAPI 3.1, SQLite, pytest and a responsive browser client. Learners progressively build Northstar Commerce, combining an e-commerce catalog, a small CRM and atomic order processing.

## Learning outcomes

- Assess FastAPI as middleware for browser, application and database connections.
- Integrate data and reusable Python functions through typed FastAPI routes.
- Support REST API integration with JSON and an OpenAPI 3.1 contract.
- Test and diagnose FastAPI-to-SQLite behaviour with Swagger UI, pytest, logs and VS Code.
- Improve validation, compatibility, performance and security controls.

## Topics covered

1. REST contracts, HTTP semantics and evidence-led AI prompting
2. FastAPI routing, reusable services, dependencies, API keys and CORS
3. Pydantic request/response models, validation and PATCH semantics
4. Structured errors, request tracing, pytest and VS Code debugging
5. SQLite relational design, parameterized SQL, CRUD and order transactions
6. OpenAPI documentation, browser integration, health checks and packaging
